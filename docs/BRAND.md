# RoomDeck Audio Brand Guidelines

RoomDeck Audio should feel modern, premium, intelligent, minimal, and connected.

## Logo

- Prefer dark backgrounds.
- Maintain clear space equal to the height of the `R`.
- Do not distort, rotate, recolour, or add effects to the supplied artwork.
- Use the RD monogram for launcher icons and compact product marks.
- Use the full RoomDeck Audio lockup for marketing and sign-in or splash contexts.

## Colours

| Role | Value |
| --- | --- |
| Background | `#0F1117` |
| White | `#F7F8FA` |
| Blue | `#3B82F6` |
| Purple | `#7C4DFF` |

## Typography

- Headings: Inter SemiBold where available, with the macOS system semibold face as the native fallback.
- Body: Inter Regular where available, with the macOS system regular face as the native fallback.

The supplied one-page [Brand Guidelines PDF](brand/RoomDeck-Audio-Brand-Guidelines.pdf) is the visual source of truth.
